Privacy Policy

Last updated: November 4, 2026

This policy covers the Polaris browser extension and website. The website analytics disclosures below supplement the extension’s data-handling policy.

1. Information We Process

Website Content

Polaris: AI Chat Navigator accesses the text and document structure of AI-generated responses displayed on supported websites. When complete indexing is enabled for ChatGPT or Gemini, it also requests the current conversation's active branch of user-visible messages through the selected site's same-origin session to build a complete outline and full-text search index. This index stays in memory across DOM removal and is cleared on conversation changes, page refresh or closure, or disabling complete indexing. While complete mode is enabled, the ChatGPT page bridge may also keep filtered snapshots of recently opened conversations for up to 60 seconds to reuse the site's own loading work, limited to three snapshots per private or shared conversation type. These temporary snapshots contain only the active branch's user-visible messages, are invalidated when an account or workspace change is detected, and are cleared when complete mode is disabled or the page closes. Complete indexing also stores a gzip-compressed snapshot of the active branch's user-visible messages and parsed records in the extension's own local IndexedDB, isolated by a confirmed account, workspace, and conversation. These snapshots are not synchronized or uploaded. Unknown identities and private windows skip persistent caching. Hidden reasoning, tool messages, alternate branches, and downloaded attachments are not included in the cache. This access is necessary to identify headings and list structures, generate navigation markers, scroll to selected sections, and show AI response content in the full-screen text-selection feature, and support user-initiated conversation copying and file export.

Website content is processed locally within the user's browser. It is not transmitted to the developer or to any third-party server. Complete ChatGPT and Gemini indexing uses the existing page session to authenticate same-origin requests to the selected site. Short-lived authentication data remains in the page context and is never placed in extension messages, diagnostic logs, persistent storage, or synchronization. Polaris does not ask for passwords.

Extension Settings

Polaris: AI Chat Navigator stores user preferences such as top and right spacing, the maximum number of visible markers, tooltip width, enabled heading levels, and unordered-list marker preferences. The complete-conversation reading preference applies to ChatGPT and Gemini across subsequent conversations. It is synchronized with the other preferences; when browser synchronization is enabled, it can enable complete reading in other signed-in browsers where the feature is available. Conversation snapshots themselves are never synchronized.

These settings are stored using the Chrome Storage Sync API. If browser synchronization is enabled, the settings may be synchronized across the user's signed-in Chrome browsers by Google under Google's applicable privacy terms. The developer cannot access these synchronized settings.

Trials, Purchases and Licenses

Polaris can contact its license service to initialize a seven-day trial, obtain available plans and validate an existing license. It generates a random installation identifier and independent credential; these, device activation credentials and pending purchase claims are stored in Chrome Storage Local and are not synchronized. Free platform choices stay on the device. No Polaris account or hardware fingerprint is required.

When you choose to purchase, Stripe-hosted Checkout processes payment and collects your checkout email. Card information is not stored by the extension or license service. The Cloudflare Worker and D1 service store the order, license and activation records needed for fulfillment and validation. License and activation verifiers are hashed; email and license delivery material are encrypted separately for delivery and recovery. Configured transactional email delivery uses Resend. Neither payment nor licensing includes AI conversations, prompts, browsing history, full browsing URLs or hardware fingerprints.

A recovery request uses the checkout email and returns the same confirmation whether or not a matching purchase exists. The service uses short-lived hashed-IP counters and delivery throttling to limit abuse. The test integration is separate from a production billing rollout, and local UI previews do not charge a payment method.

Diagnostic Logs

If the user explicitly selects a diagnostic action in About & Settings, Polaris: AI Chat Navigator records a bounded session-only log for the current tab. The log contains the extension version, coarse platform and browser summaries, viewport measurements, pointer-drag lifecycle outcomes, route and render counts, and error type names. It is designed to exclude AI response text, marker titles, full URLs, account information, prompts, cookies, tokens, error messages, and stack traces. Complete-reading events may also include a cache-hit flag, stage durations, and a count of additional history-page requests.

The log is stored only in the current tab's session storage until the tab is closed or the session is cleared. "Download only" saves a redacted JSON file locally. "Send diagnostic log" also opens a pre-addressed email draft to jefferyho.build@gmail.com; the browser does not automatically attach the local file, so the user chooses whether to attach and send it. Polaris: AI Chat Navigator does not upload diagnostic logs or add a background upload service.

Clipboard

When the user activates a copy action, Polaris: AI Chat Navigator writes the selected text, a chapter, or conversation text to the system clipboard. Full-conversation copying includes user messages and AI replies in the active branch and is independent of chapter filters or folding. Complete-index copying is available only after reading finishes; page-based copying includes only content already read from the page. The extension does not read existing clipboard content or upload copied text. Clipboard contents are managed by the user's operating system and any clipboard tools the user has enabled.

Conversation File Export

After copying a conversation, the user can explicitly save the same message scope as Markdown or HTML. Files are generated locally in the browser and downloaded to a location managed by the user; conversation text is not sent to a processing server. Exported images are represented by text labels, and raw message HTML is sanitized or escaped. Normal links remain clickable; following them contacts their destination. Downloaded files remain until the user deletes them, independently of the extension's cache. Any sharing or cloud backup of these files is controlled by the user and the applications or services they choose.

The extension does not use information for:

  • Advertising or personalized advertising;
  • Analytics or behavioral tracking within the extension;

Polaris: AI Chat Navigator does not sell, rent or trade personal information. AI website content is not shared with the developer, advertisers, data brokers or other third parties. Payment and license information is processed only by the services described above to provide the requested purchase, authorization, delivery and recovery features.

External processing includes license-service requests, user-initiated Stripe Checkout and license email delivery, optional synchronization of extension settings through Chrome Storage Sync, and the user's explicit choice to open a diagnostic file or email draft. 4. Data Retention

Default mode does not persist AI responses or user prompts. Opt-in complete ChatGPT and Gemini indexing caches user-visible conversation text and parsed records locally, with a total compressed limit of 100 MiB. Least-recently-used entries are removed when space is needed. Snapshots remain after closing a tab or disabling complete mode until the user selects Clear conversation cache in Preferences, entries are evicted, or the extension is removed. Clearing also invalidates pending old cache writes. The cache does not retain Maker navigation history or authentication credentials.

Extension settings remain in Chrome storage until they are reset or removed by the user through the browser or extension settings. Synced settings may also be managed through the user's Google Chrome synchronization settings.

Diagnostic events remain in session storage for the current tab, are bounded in count and size, and are cleared when the tab session ends or when the browser clears session storage. A downloaded copy remains under the user's control, and any email retention is governed by the user's mail provider and choices.

Local installation and activation credentials remain until the extension is removed or its local storage is cleared. Device deactivation revokes its activation credential but retains the installation identity and trial deadline. Test license delivery ciphertext and order records remain for the lifetime of that test license; delivery retry metadata does not contain plaintext credentials. Short-lived rate-limit counters are periodically deleted. Contact the developer about deleting server-side test purchase and license records.

The extension requests only the permissions needed to provide its disclosed functionality.

隐私政策

更新日期：2026 年 11 月 4 日

本政策涵盖 Polaris 浏览器扩展与官网。下方官网分析说明补充扩展的数据处理政策。

1. 我们处理的信息

会话内容与完整读取

Polaris 在浏览器本地读取受支持 AI 网页的回复内容与文档结构，用于目录、导航、搜索和阅读。开启 ChatGPT 或 Gemini 完整读取后，会使用当前网页已有登录态，通过同源请求补全当前会话活动分支中用户可见的消息。这里的“用户可见”不表示私人会话被公开。

当前索引保留在内存中，切换会话、刷新或关闭页面、关闭完整读取时清除。完整模式开启期间，ChatGPT 页面桥接还可短暂保留最近打开会话的已过滤快照，以复用原站加载结果；私人和分享会话各最多三份，最长 60 秒，检测到账号或工作区变化后失效，关闭完整模式或页面时清除。

完整读取会将活动分支的用户可见消息及解析记录以 gzip 压缩快照存入扩展自己的本地 IndexedDB。缓存按确认的账号、工作区和会话隔离，不同步、不上传；身份未知或隐私窗口跳过持久化。缓存不包含隐藏推理、工具消息、其他分支或下载的附件内容。正文不发送给开发者或第三方处理服务器。短期鉴权信息留在网页环境中，不进入扩展消息、诊断日志、持久化存储或同步；Polaris 不索要密码。

扩展设置

间距、显示数量、提示宽度、识别范围等偏好存于 Chrome Storage Sync。完整读取偏好适用于 ChatGPT、Gemini 及后续会话；开启浏览器同步后，也可在其他已登录且具备相应功能的浏览器生效。会话快照本身不会同步。同步由 Google 按其适用政策处理，开发者不能访问同步设置。

试用、购买与许可证

扩展可联系许可服务以初始化七天试用、获取方案和验证许可证。随机安装标识、独立凭据、设备激活凭据及待确认购买信息存于 Chrome Storage Local，不同步；免费平台选择留在本机。无需 Polaris 账号，不使用硬件指纹。

用户选择购买后，由 Stripe 托管 Checkout 处理支付并收集结账邮箱，扩展与许可服务不保存银行卡信息。Cloudflare Worker 和 D1 保存履约、验证所需的订单、许可及激活记录；许可和激活验证值经过哈希处理，邮箱与许可交付材料分别加密。配置的事务邮件由 Resend 发送。这些流程不包含 AI 会话、提示词、浏览历史、完整浏览网址或硬件指纹。

找回请求使用结账邮箱，无论是否存在匹配购买均返回相同确认；短期 IP 哈希计数与发送限速用于防滥用。测试集成与正式收款发布分开，本地界面预览不会扣款。

诊断日志

用户在设置中主动选择诊断操作后，扩展为当前标签页记录有条数和大小上限的会话日志，包括版本、粗粒度平台与浏览器信息、视口、指针拖动结果、路由和渲染次数、错误类型；完整读取事件还可包含缓存命中、阶段耗时和额外分页请求数。白名单设计排除正文、目录标题、完整网址、账号、提示词、Cookie、令牌、错误消息和堆栈。

日志仅存于当前标签页 sessionStorage。“仅下载”保存脱敏 JSON；“发送诊断日志”另打开预填至 jefferyho.build@gmail.com 的邮件草稿，不自动附加文件，由用户自行决定附件和发送。扩展不自动上传日志。

剪贴板与导出

用户主动复制时，扩展将所选文本、本章或会话文本写入系统剪贴板，不读取原有剪贴板、不上传复制正文。会话复制包含活动分支的用户消息与 AI 回复，不受章节筛选或折叠影响；完整索引读取结束后方可复制，页面来源仅包含已读取内容。剪贴板由系统及用户启用的剪贴板工具管理。

复制后可主动保存相同范围的 Markdown 或 HTML，由浏览器本地生成下载，不发送至处理服务器。图片转为文字标签，原始 HTML 经清洗或转义；普通链接仍可点击，点击后会访问其目标。下载文件由用户保存和删除，不受扩展清缓存操作影响；分享及云备份由用户选择的应用或服务处理。

扩展设置保留至重置、清除或卸载；同步设置也可在浏览器同步设置中管理。诊断日志随标签页会话结束或 sessionStorage 清除而删除；已下载文件及已发送邮件由用户和邮件服务商管理。

11. 官网分析、托管与外部链接

仅在用户选择“允许分析”后，官网才初始化 Google Analytics 4 和阿里云 SLS 分析并发送事件。SDK 文件可提前加载，但同意前不初始化或发送分析事件；GA 自动页面访问关闭。用户可拒绝并继续使用网站，或从首页页脚“分析设置”更改选择。

GA 仅统计扩展支持入口到达及视频恢复播放按钮点击；SLS 统计已同意的页面到达和本地 ZIP 下载操作。事件可含 UTM、固定扩展来源 polaris_extension 或无参数时的 direct_share/direct，以及归一化设备、浏览器、系统、视口和语言类别。直接来源也包括书签、输入网址及参数被移除的链接；下载事件不证明文件已成功保存。

上述事件字段不含原始 User-Agent、设备型号、IP、完整网址、AI 会话、扩展设置、账号或支付详情。但网络连接仍会向接收请求的托管、安全或分析服务商暴露 IP 等连接信息。阿里云及交付链路中使用的 Cloudflare 等托管、安全服务商可为网站交付和保护处理请求元数据及必要安全 Cookie；这与可选分析事件不同。

语言、主题和分析选择保存在本地浏览器；法律页面不初始化分析，也不请求会话内容。官网价格介绍不初始化扩展试用，也不直接开启收款。

第三方政策：Google、阿里云 SLS SDK、阿里云隐私信息、Cloudflare、PayPal。SLS 浏览器日志投递使用临时 STS 凭据。

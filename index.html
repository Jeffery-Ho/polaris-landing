Install Polaris AI

Choose the installation method that works best for you.

Local installation

Download the ZIP, unzip it, then load the folder in Chrome extensions.

Download ZIP Downloading…
  1. Download and unzip the offline ZIP package.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and select the unzipped Polaris folder.
  4. Refresh the AI chat page to start using Polaris.

Chrome Web Store

Requires access to the Google Chrome Web Store. Install Polaris with one click.

Install from Chrome Web Store

The extension will be added to Chrome after you confirm the installation in the store.

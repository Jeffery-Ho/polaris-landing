November 2026

v0.108.0Nov 5

Your two free platforms

  • Choose two free platforms at the end of onboarding, and change them anytime from the top platform icon. Switch between supported platforms, replace a free platform, or explore Pro for access to every platform. Your full-access trial and saved local data are preserved.

v0.107.0Nov 5

One conversation index across platforms

  • Virtual TOC and Outline now share structured message indexing across supported platforms, retaining loaded replies, file labels and images as pages change. Kimi recognizes formatted paragraph titles and keeps replies under their questions. Available native history can be read progressively; unconfirmed history stays labeled as loaded content.

v0.106.0Nov 5

Continue with another AI

  • The export dialog now includes a copyable prompt for continuing a conversation with another AI. It asks the AI to recap the last three exchanges before continuing, and distinguishes complete history from partially read conversations.

v0.104.0Nov 5

Export attribution

  • Markdown and HTML exports now end with a local-export attribution using the published app name.

v0.102.0Nov 5

Copy and export conversations

  • Copy the conversation from the top right of the content area, then optionally save Markdown or HTML. Section menus now copy only the selected section.

v0.100.0Nov 5

Find reply text in Outline

  • When TOC has no reply entries, use the new shortcuts to adjust the display range in Settings or read body text in Outline.

v0.94.0Nov 5

A new sidebar surface

  • A subtle dotted background, outlined assistant cards and gray user bubbles bring a clearer hierarchy to the sidebar. Outline keeps a solid reading surface, with matching dark-mode colors.

v0.93.0Nov 5

Pro at the top of Settings

  • A terracotta card with a pearl star replaces the Pro menu entry. It opens purchases or pending progress, and stays visible for Pro members to view their membership details.

v0.92.0Nov 5

Discord community

  • Feedback now includes a Discord community entry beside X and Xiaohongshu.

v0.91.0Nov 5

Locate the current Maker

  • The scroll toolbar now has a Locate current Maker button. Return to the active Maker in the TOC, including off-screen entries in long conversations.

v0.90.0Nov 5

Pro and license

  • Adds purchase, license redemption, recovery and device deactivation in Settings. A seven-day full-access trial leads into Free with two changeable platforms.

v0.88.0Nov 5

Simpler full-conversation search

  • Removed the search scope selector. Search all message text with fuzzy matching, original-text highlights and source navigation.

v0.87.0Nov 5

User image labels and stable reading

  • User image attachments are indexed as image labels. Reading survives background tabs and reuses recent conversations. The reading cover returns, with refresh offered only after failure.

v0.86.0Nov 5

All conversation groups in the full index

  • The full-history TOC now includes every indexed question and Image label directly, without an earlier-groups summary. Virtual scrolling keeps the mounted list small, and individual questions can still be folded.

v0.85.7Nov 5

Locate images in shared chats

  • Image entries now ask ChatGPT's existing virtual list to mount the source message, then locate and highlight it. ChatGPT continues to own image loading and rendering.

v0.85.6Nov 5

Read shared chats in the signed-in app

  • Full reading now handles the signed-in shared page's reload response using the existing page session and the shared-chat data endpoint. All Image labels continue through the same full index and virtual list without image downloads.

v0.85.5Nov 5

A separate reader for shared chats

  • Shared chats now use their own server data reader, supporting the route's raw loader response and an HTML compatibility fallback while preserving the same full index and Image labels.

v0.85.4Nov 5

Reuse shared-chat server data

  • Full reading now reuses the complete server data already loaded by the active shared chat, including image messages beyond the mounted page. It waits briefly for page initialization when necessary and cancels safely when the source changes.

v0.85.3Nov 5

Shared-chat read recovery

  • If a shared-chat refetch returns an unreadable format, Polaris can recover its full history from the matching server snapshot already received by the page, including image labels beyond the mounted messages.

v0.85.2Nov 5

Read failure diagnostics

  • Downloaded diagnostics now include safe error codes, elapsed time and message counts when a full-conversation read fails, helping identify failures on shared chat pages.

v0.85.1Nov 5

Image labels in shared chats

  • Follow ChatGPT mode now includes already displayed AI image replies, including image-only shared turns, without downloading previews. Full-history mode continues to read earlier image messages from the server.

v0.85.0Nov 5

Image labels without downloads

  • All AI image messages appear as Image labels in the TOC and Outline, with source navigation and no preview downloads or sampling.
  • Fixes Gemini initialization when the page replaces its body while settings are loading.

v0.84.2Nov 5

AI images in the TOC

  • The full-history TOC now includes AI image replies with lazy previews and original-image links. Markdown sandbox images work in both original and shared conversations.

v0.84.1Nov 5

Neutral Outline backgrounds

  • Collapse controls and image placeholders now use neutral gray backgrounds instead of the accent tint.

v0.84.0Nov 5

Read the full history of shared chats

  • Shared ChatGPT conversations now read their complete server history, including AI image replies beyond the currently visible messages.

v0.83.1Nov 5

Scroll controls follow the current list

  • Floating scroll buttons now appear only when the TOC or Outline shows list rows. Settings, empty lists, and other states keep them hidden.

v0.83.0Nov 5

Read images in long conversations

  • Reading now shows Markdown images and generated image attachments in reply order. Images load as you read, open their originals in a new tab, and keep a retry option if loading fails.

v0.82.1Nov 5

Show scroll controls with conversation content

  • The floating scroll buttons stay hidden when no conversation has been read, while loading, or after reading fails, and return when conversation content is ready.
